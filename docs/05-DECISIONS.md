# 05 — Decisions I took on your behalf

*You asked me to answer my own open questions with the best suggested answer and to keep going without stopping. This is that record. Every one of these is a real, reversible decision with a stated rationale, and the code already reflects it. Say the word on any line and I reverse it — the cost is a refactor, not a re-think.*

| # | Question I would have asked | Decision taken | Why this is the best default |
| --- | --- | --- | --- |
| 1 | One insurer, a group, or SaaS sold to many insurers? | **Multi-tenant capable, pilot shaped as one operator group with two legal entities** (conventional + takaful window). Tenancy is a first-class dimension; the demo runs a single group. | Multi-tenant costs nothing to design in and everything to retrofit. Starting with a group exercises the hardest finance path (two entities, one consolidation) immediately. |
| 2 | Which country pack first? | **UAE (CBUAE-flavoured) first, Malaysia (BNM) second.** Both are implemented as data with their differences (surplus-to-savers restrictions, cooling-off, need-analysis triggers). | You work in Dubai, the takaful rules are strictest-but-clearest in the UAE, and Malaysia is where takaful operations are most mature — it proves the pack architecture is genuinely portable. |
| 3 | Are we the fund manager or do we consume third-party NAVs? | **Both: the platform runs its own NAV engine, and accepts administrator/vendor files.** The seeded world prices funds from an administrator-style file. | Owning the engine is the ILAS-beating claim; accepting external NAVs is what every real operator needs on day one. |
| 4 | Payment rails and wallet vs arrears for daily/PAYG cover? | **Prepaid wallet first, arrears as a product option.** Cover suspends rather than part-charging into a negative balance. | Prepaid removes credit risk from micro-duration cover, which is the only way insurers will underwrite a 12.50 AED day of motor cover profitably. |
| 5 | Takaful first, or conventional-with-takaful-window first? | **Conventional + takaful window in one tenant first**, with full pool segregation, because that is the harder problem and it subsumes the standalone case. | A window that stays pure can be extended to a standalone entity trivially; the reverse is not true. |
| 6 | Legacy book migration (ILAS or another core)? | **No migration in v1**; the ingestion fabric is built to absorb any shape of file, which is what a migration actually needs before it needs a mapping tool. | You have no book to move today. Building migration tooling before the target schema settles wastes the work. |
| 7 | Stack? | **TypeScript end-to-end (core, server, console), Postgres-shaped domain model, event-ready outbox.** No framework lock-in; the API server is plain Node so it runs anywhere. | One language maximises agent throughput and keeps the domain readable by humans reviewing regulated logic. |
| 8 | How far can AI agents go? | **Agents propose; humans dispose.** Payouts above limits, final pricing, Shariah rulings, actuarial certification, surplus distribution and any ledger override are on a prohibited list the runtime enforces. | This is exactly where regulators are converging, and it is also the difference between a tool that gets approved and one that does not. |
| 9 | Multi-bilingual scope? | **English and Arabic first-class (with RTL-ready labels), then Malay/Indonesian, Urdu, French, Chinese in the backlog.** Data translation is kept separate from label translation. | Arabic is mandatory for the UAE; keeping the two translation concerns apart is what makes a scanned Arabic name safe to display in English. |
| 10 | What does "finished" mean? | **The phase gates in `04-PHASES.md`, evidenced by the money proof and the regulatory journeys** — not a date. | The fleet works a chunk at a time; pretending to know a finish date would be theatre. |
| 12 | How does a customer actually open the demo when the sandbox preview is gated? | **Publish the demo as static pages** (`demo/site/index.html` + the offline console + the gallery) and hand over a plain HTTPS link; the sandbox preview URL is treated as a bonus, never as the route. The Pages workflow assembles the site, and a raw-code host (raw.githack) serves the same committed files immediately. | An access token sitting on a proxy is not something a customer can be asked to work around, and a video is not the product. A committed, self-contained page opens from any browser, in any country, with no port, tunnel, token or install — and the offline console is the real application, so what they test is what we ship. |
